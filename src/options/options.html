Everything is stored locally in this browser. Changes save automatically.

Rules

Mark tabs automatically by site. The domain can include a path (github.com/my-org), and the optional keyword must appear in the URL or title. The first matching rule wins; a color you pick by hand always overrides it.

Quick labels

Shown in the popup and right-click menu, organised in groups. Rename a group by editing its name, move labels between groups with the Group column, or create a new one. Picking a label also applies its auto color (unless you chose a color by hand); icon style and symbol override the display setting for tabs with that label.

Colors

Set the emoji each color shows in the tab title, hide colors you don't use, or add your own.

Custom colors

Keyboard shortcuts

Assign or change keys in Brave at brave://extensions/shortcuts.

Backup

Export everything — rules, labels, colors, settings and the notes & marks of open and recently closed tabs — to a JSON file. Importing replaces settings; notes & marks go back onto matching open tabs and the rest to “Recently closed”. Nothing existing is overwritten.

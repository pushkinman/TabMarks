Rules

Automatically mark tabs by site. The domain can include a path (e.g. github.com/my-org); the optional keyword must appear in the URL or page title. First matching rule wins. A color you pick by hand always overrides a rule.

Quick labels

Shown in the popup and right-click menu, grouped. A label's color is applied automatically when you pick the label (unless you chose a color by hand). Icon style / symbol override the global display setting for tabs with that label. The Pull requests group is what the “Cycle PR status” shortcut steps through.

Colors

Edit the emoji used in the tab title for each color, hide colors you don't use, or add your own.

Custom colors

Keyboard shortcuts

Change these in Brave at brave://extensions/shortcuts.

Backup

Export rules, labels, colors and settings (plus a read-only snapshot of notes on open and recently closed tabs) to JSON, or import a previous export. Everything is stored locally in this browser only.
